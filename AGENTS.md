# AGENTS.md — Симпл Квиз

## Цель проекта

Проект хранит каталог вопросов «Симпл Квиз», архив публичного Telegram-канала
`@simple_quiz`, результаты OCR и автономную HTML-версию базы.

## Язык работы

- Общение, документация и пользовательские статусы — на русском языке.
- Имена файлов, программные идентификаторы и команды могут быть на английском.

## Источники истины

1. `data/source/Simple_Quiz_Intelligence_base.json` — исходные таблицы проекта.
2. `telegram_archive/manifest.json` — манифест публикаций и доступных медиа.
3. `telegram_archive/questions.json` — распознанные карточки до дедупликации.
4. `telegram_archive/questions_enriched.json` — вопросы с результатами дедупликации.
5. `telegram_archive/question_analysis.tsv` — редакторский анализ новых вопросов.
6. `scripts/` — воспроизводимый процесс архивации, OCR и сборки.

HTML-файлы в `outputs/` и корневой `Simple_Quiz_Intelligence_*` являются результатами
сборки. Не редактировать их вручную, если изменение можно внести в источник или
скрипт.

## Правила работы

- Перед изменениями выполнять `git status --short --branch`.
- Работать в отдельной ветке; одна задача — одна ветка и один логический набор
  коммитов.
- Не удалять пользовательские или несвязанные изменения.
- Не добавлять в Git `telegram_archive/media/`: архив тяжёлый и хранится локально.
- Целевой формат проекта — автономный HTML; XLSX не создавать и не добавлять.
- Не подставлять предполагаемые ответы. Если ответ не подтверждён, оставлять
  `Не опубликован в посте` и соответствующий статус проверки.
- При изменении правил OCR или дедупликации сохранять `postId`, URL публикации,
  локальный путь к карточке и коэффициент уверенности.
- Ссылки на источник хранить как обычный текст URL.

## Сборка

```bash
npm run extract
npm run enrich
npm run build:html
npm run verify
```

Полная повторная выгрузка Telegram выполняется отдельно, так как требует сети:

```bash
npm run refresh:telegram
```
