# Совместная работа

## Ветки

Используйте короткие ветки:

- `feature/<задача>` — новая возможность;
- `data/<источник>` — обновление данных;
- `fix/<ошибка>` — исправление;
- `docs/<тема>` — документация.

Пример:

```bash
git switch -c data/telegram-july
```

## Перед началом

```bash
git status --short --branch
git pull --ff-only
```

Прочитайте `AGENTS.md` и убедитесь, что локальный медиархив находится в
`telegram_archive/media/`.

## Перед коммитом

```bash
npm run verify
git diff --check
git status --short
```

Коммит должен описывать результат, например:

```text
data: import Telegram quiz cards
```

## Pull request

В описании укажите:

- что изменено;
- какие источники использованы;
- сколько вопросов добавлено и сколько признано дубликатами;
- какие проверки выполнены;
- что требует ручной проверки.

Для передачи незавершённой задачи используйте `docs/HANDOFF_TEMPLATE.md`.
